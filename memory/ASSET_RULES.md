# Portfolio Asset Rules

Use these rules when adding, replacing, or auditing images and visual evidence.

## Naming

- Prefer descriptive names: `project-section-state.png`.
- Examples:
  - `aitryon-home-before.png`
  - `aitryon-home-after.png`
  - `aitryon-seo-tool-before.png`
  - `aitryon-ai-studio-flow.png`

## Usage

- Official site assets live under `assets/brand/`, `assets/cases/`, and `assets/resume/`.
- Reference or placeholder imagery belongs in `assets/references/`, not inside a case folder.
- Process screenshots and temporary visual review captures belong in `working/screenshots/`.
- Use wide media only for major narrative breaks.
- Use contained media for interface screenshots that support body text.
- Prefer cropped UI modules or diagrams over only long full-page screenshots.
- Every case image should either show product evidence, process evidence, or outcome evidence.

## Audit Checks

- Check missing referenced files.
- Check unreferenced assets.
- Check duplicate file sizes or duplicate hashes.
- Check very large assets that may slow local preview.
- Check empty or weak `alt` text when images are content-bearing.
